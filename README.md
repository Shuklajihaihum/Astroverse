# AstroVerse AI

A futuristic, responsive Next.js landing experience for an AI-powered astronomy ecosystem. It introduces the core product through an animated space interface, research discovery UI, intelligent search, community signals, and reusable visual patterns.

## Run locally

Install dependencies, then start the development server:

```bash
pnpm install
pnpm dev
```

The experience is implemented in `app/page.tsx`, with global visual language in `app/globals.css`.

## Planned product modules

The UI establishes the shared system for the eventual research, AI assistant, explorer, AstroFlix, bookstore, blog, collaboration and dashboard modules. Authentication and database integration are intentionally represented as frontend-ready placeholders.
